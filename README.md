# Paint Team 3D v3 — мобильная версия

Готовый прототип с нормальным управлением для телефона.

## Что внутри
- Карта и все переданные GLTF-модели.
- Синий игрок.
- Красный, зелёный и жёлтый противники.
- Пушка.
- Четыре цветные банки.
- Виртуальный джойстик слева.
- Управление обзором свайпом справа.
- Кнопка «КРАСКА» для стрельбы.
- HP и боезапас.
- Простое преследование противниками.
- GitHub Actions для сборки APK.

## GitHub
Загрузи содержимое этой папки в репозиторий целиком. После push открой Actions → Build Paint Team 3D APK. После успешной сборки APK будет в Artifacts.

## Важно
Эта версия специально сделана как чистый Godot-проект, чтобы GitHub не пытался собирать старую Java/Gradle-структуру без папки `app`.
