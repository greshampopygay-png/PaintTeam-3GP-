# Paint Team 3D v2

Новая мобильная версия прототипа Paint Team:
- горизонтальный экран;
- виртуальный джойстик слева;
- кнопка «КРАСКА» справа;
- движение и стрельба;
- HP и возрождение;
- красная и синяя команды;
- две большие 3D-стилизованные цистерны;
- урон цистернам;
- боты для одиночного тестирования.

Важно: это локальный игровой прототип. Настоящий сетевой режим до 30 игроков требует отдельного серверного backend. В этой версии сначала проверяем управление и механику на телефоне.
